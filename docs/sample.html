Step 5 up close: what counts as important news

Found while tracing

  • One record is per chat, the other per project. The fingerprint of the last publish (published) lives with each chat. The link and the commit saved at publish (.local.json) are shared by the whole project. A publish from another chat moves the commit that step 6 compares against, but not this chat’s fingerprint.
  • A commit alone never republishes. Step 6 only matters when step 3 already said the link is out of date. If the map page is unchanged, the code just updates the saved commit and does nothing else.
  • Every-change mode skips the news memory. In that mode the notice is never worked out, so notable.json is not updated and nothing is remembered as told.
